# Weather Dashboard (Vanilla HTML/CSS/JS)

A sleek, responsive, glassmorphic weather application built with zero frameworks and zero dependencies.

---

## 🚀 How to Run

```bash
python3 server.py
```
*(Automatically starts an HTTP server at `http://localhost:3000` and opens your default browser).*

Or open directly:
```bash
xdg-open index.html
```
